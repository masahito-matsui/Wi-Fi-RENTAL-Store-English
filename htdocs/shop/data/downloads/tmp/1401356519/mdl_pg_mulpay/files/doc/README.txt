EC-CUBE GMO-PG決済モジュール

======================
EC-CUBE 対応バージョン
======================
  2.13.0
  2.13.1

  ※ 本モジュールは、上記バージョンのEC-CUBEにのみ対応しております。

  ※ 2.13.0未満のEC-CUBEではご利用できません。そちらに対応したGMO-PG決済
